Activate The Ball

A physics-first Unity 2D game with progressive level design.

C#Unity 2DPhysicsUI Design

Learn More

What I Built

  • Developed the game in Unity 2D with C#, implementing collision detection and response through the 2D physics engine.
  • Designed and arranged progressively harder levels and created the user-interface elements that guide play.
  • Used the project as my first end-to-end experience designing and building a game in Unity.
  • Defined a clear core mechanic: make the ball bounce off the table exactly as many times as the displayed target.
  • Built level progression so completing the objective immediately advances the player.
  • Increased difficulty over time with moving obstacles that require better timing and control.
