What I built

  • Built a C++ pipeline in CARLA to generate and label 10,000+ bird’s-eye-view training images.
  • Developed a ResNet-50 model in PyTorch for parking-space detection.

From simulator cameras to a labeled dataset

The public implementation connects Python vision tools to C++ capture automation through gRPC. It pairs rendered images with vehicle poses and parking-space geometry, building the data foundation for parking-space detection.

  1. Build a surround view

    Four CARLA cameras capture the front, rear, left, and right of the vehicle. Python and OpenCV apply perspective transforms, rotate and flip the views, and assemble them into a shared Pygame bird’s-eye preview.

  2. Tune camera alignment

    Tkinter calibration panels expose camera position and rotation, source/destination transform settings, output dimensions, and placement offsets. These controls help align parking markings across the stitched views.

  3. Define parking-space geometry

    An interactive labeling tool uses RGB and depth cameras to turn selected image points into world coordinates. Each parking space is saved as an ID and four corners in JSON, then can be drawn back into the simulation for inspection.

  4. Automate varied captures

    The C++ capture tool moves the vehicle through a parking-lot grid and sweeps its heading from −180° to 180° in 10° steps. Collision and position checks gate capture, while received frames are matched to the target location.

  5. Pair images with structured metadata

    A Protocol Buffers contract carries image data, vehicle position/orientation, and the bird’s-eye field boundary between Python and C++. The C++ processor saves images and records poses plus intersecting parking-space IDs in transforms.json. A Python SQLite builder organizes image metadata and parking-space corners into separate tables.

  6. Develop the ResNet-50 detection model

    A custom PyTorch model uses a pretrained ResNet-50 backbone with separate heads for parking-space confidence and four-corner coordinates, supporting up to 10 spaces per image. A dataset loader joins captured images with vehicle transforms and parking-space labels from SQLite. The training prototype includes noise, blur, and color augmentation, an 80/20 training/validation split, Adam optimization, and a combined confidence and corner-regression loss.
